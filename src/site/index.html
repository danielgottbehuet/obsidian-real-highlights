Obsidian plugin

Highlights that look like ink on paper.

Real Highlights turns your ==highlights== into realistic highlighter pen strokes – organic edges, slanted chisel tips, a little extra ink where the pen touches down.

Install View on GitHub

Why it feels real

Works with what you have

Uses Obsidian's native ==highlight== syntax. Your notes are never changed – turn the plugin off and the regular highlights come back.

Unique, yet stable

Every stroke is generated from the highlighted text: each one looks different, but the same highlight always looks exactly the same when you reopen a note. No images are stored.

One stroke per line

Highlights that wrap get a separate stroke on every visible line and adapt when the window is resized.

Reading view & Live Preview

Strokes are drawn behind the text. Cursor, selection and line heights stay untouched; source mode stays as it is.

Highlight colors

Supports Obsidian's colored highlights like ==🔴text== with a pen color for each: red, green or blue.

Light & dark

Ink-like blending on light themes, readable strokes on dark themes. English and German interface.

Five presets

Try it yourself

Same text, same stroke – change a letter and the stroke changes.

Community plugins

Coming soon

Once approved: Settings → Community plugins → Browse, search for “Real Highlights”, install and enable.

BRAT (beta)

Install the BRAT plugin, run “Add a beta plugin for testing” and enter danielgottbehuet/obsidian-real-highlights. You'll get updates automatically.

Manual

Download main.js, manifest.json and styles.css from the latest release into .obsidian/plugins/real-highlights/ and enable the plugin.

Requires Obsidian 1.8.7 or newer. Tested on desktop (macOS) with 1.13.7 and 1.15.1.
